# PACT — Portal Administrativo de Centro de Treinamento

O **PACT (Portal Administrativo de Centro de Treinamento)** é uma aplicação voltada à gestão administrativa de centros de treinamento.

O projeto tem como objetivo centralizar e facilitar o gerenciamento das principais rotinas administrativas da instituição em uma única plataforma.

## Status do projeto

O PACT está atualmente **em desenvolvimento**.

Funcionalidades, melhorias e mudanças estruturais ainda podem ocorrer ao longo da evolução do projeto.
